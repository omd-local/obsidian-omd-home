# Remote Work Desk Equipment Inventory

This synthetic distractor records physical desk equipment. It is not an account
security guide and contains no problem-remedy pairs for authentication safety.

## Devices

- One 27-inch display
- One USB-C dock
- One external keyboard
- One adjustable desk lamp

## Maintenance

Clean the display monthly and check the dock cable for visible wear. Replace the
lamp bulb when its output becomes uneven.
