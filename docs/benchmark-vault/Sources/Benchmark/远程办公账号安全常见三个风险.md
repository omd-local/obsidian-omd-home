# 远程办公账号安全常见三个风险

这是一篇合成的 benchmark 笔记，用来验证 OMD Home 能否跨主题识别三组风险与对应的安全做法，
并按用户指定的语言保持一一对应关系。

## 错误一：在公共 Wi-Fi 上传敏感文件

开放网络可能被监听，文件内容、登录状态或会话资料可能因此暴露。

### 更安全的做法

改用可信的个人热点，或先连接受信任的 VPN，再处理敏感文件。

## 错误二：多个服务重复使用同一个密码

任意一个服务泄漏后，攻击者可能使用同一组凭据尝试登录其他账号。

### 更安全的做法

为每个服务设置独立密码，并将密码保存在密码管理器中。

## 错误三：接受意外出现的 MFA 请求

没有主动登录时出现的验证请求，可能来自正在尝试进入账号的其他人。

### 更安全的做法

拒绝该请求，并立即向管理员或安全团队报告。

## English recap

Three unsafe practices are uploading sensitive files over public Wi-Fi, reusing
one password across services, and approving an unexpected MFA prompt. The
corrections are use a trusted hotspot or VPN, use unique passwords stored in a
password manager, and deny the unexpected prompt; report it to security.
